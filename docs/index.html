节能模式

侧边栏底部常驻的电源方案开关：点一下在节能和高性能之间切换，状态实时同步。

GitHub 仓库 配置自己的方案

节能模式 高性能模式

它怎么找方案

不写死 GUID。每次读 powercfg /list，按顺序找：

  1. 你显式指定的（环境变量或配置文件）；
  2. 你自建的方案：名字像「低功耗 / 节能 / 省电 / saver」的当节能，像「高性能 / 游戏 / turbo / performance」的当高性能（Windows 自带的三个方案不参与这轮，免得挤掉你的自定义方案）；
  3. Windows 自带：节能 a1841308-…、高性能 8c5e7fda-…。

所以换台电脑也能开箱即用。

指定自己的方案

# 环境变量，值填 GUID 或名字片段
setx DSH_POWER_ECO   "低功耗"
setx DSH_POWER_TURBO "GameTurbo"
// 或 %USERPROFILE%\.dsh\power-mode.json
{ "eco": "低功耗", "turbo": "GameTurbo" }

安装

git clone https://github.com/chen-bi/dsh-power-mode.git

在 DSH 里 plugin_manager → install_bundle 指向目录，刷新页面。之后再让助手操作也行：power_mode 工具（status / eco / turbo）和按钮共用一套逻辑。

接口

方法路径用途
GET/api/power-mode/state当前模式、GUID、方案名
POST/api/power-mode/set{"mode":"eco"|"turbo"}
